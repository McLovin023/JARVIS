PROYECTO VIERNES CASA DOMOTICA inteligente

    Nuestra idea

¿Que queremos construir?

Queremos construir una casa domotica inteligente controlada mendiante un celular y conectada por Wi-Fi a una ESP32

la casa tendra diferentes componentes que permitan controlar y monitorear algunas funciones:

  1. 💡 Encender y apagar luces.

  2. 🚪 Abrir y cerrar una puerta.

  3. ☀️ Detectar la cantidad de luz ambiental.

    Estado: Soleado / Iluminado

    Lectura del sensor: 450 Lux


  4. 💧 Medir la humedad.

    Estado: Humedo / Seco

    Lectura del sensor: 100%


  5. 📱 Controlar el sistema desde un celular.

    En linea conectado

¿Por que escogimos esta idea?

Escogimos esta idea porque nos interesa la tecnología, la programación y el Internet de las Cosas (IoT).

ademas, una casa inteigente nos permite combinar varias cosas en un solo proyecto.

Prgramacion + electronica + sensores + Wi-Fi + pagina web

¿Que problama queremos resolver?

Queremos solucionar algunas situaciones comunes en una casa.

  • Dejar luces encendidad cuando no son necesarias
  • No saber si una puerta esta habierta o esta cerrada
  • No tener una forma sencilla de controlar algunos elementos del hogar
  • No poder monitorear facilmente condiciones como la humedad o la iluminacion

Nuestra propuesta busca hacer estas tareas mas comodas, automatizadas y controlables.
