PROYECTO VIERNES CASA DOMOTICA inteligente

    Nuestra idea

¿Que queremos construir?

Queremos construir una casa domotica inteligente controlada mendiante un celular y conectada por Wi-Fi a una ESP32

la casa tendra diferentes componentes que permitan controlar y monitorear algunas funciones:

  1. 💡 Encender y apagar luces.

  2. 🚪 Abrir y cerrar una puerta.

  3. ☀️ Detectar la cantidad de luz ambiental.

    Estado: Soleado / Iluminado

    Lectura del sensor: 450 Lux


  4. 💧 Medir la humedad.

    Estado: Humedo / Seco

    Lectura del sensor: 100%


  5. 📱 Controlar el sistema desde un celular.

    En linea conectado

¿Por que escogimos esta idea?

Escogimos esta idea porque nos interesa la tecnología, la programación y el Internet de las Cosas (IoT).

ademas, una casa inteigente nos permite combinar varias cosas en un solo proyecto.

Prgramacion + electronica + sensores + Wi-Fi + pagina web

¿Que problama queremos resolver?

Queremos solucionar algunas situaciones comunes en una casa.

  • Dejar luces encendidad cuando no son necesarias
  • No saber si una puerta esta habierta o esta cerrada
  • No tener una forma sencilla de controlar algunos elementos del hogar
  • No poder monitorear facilmente condiciones como la humedad o la iluminacion

Nuestra propuesta busca hacer estas tareas mas comodas, automatizadas y controlables.

Construcción

¿Cómo comenzamos

Primero diseñamos el funcionamiento de la casa y decidimos qué componentes necesitábamos.
Después realizamos pruebas individuales antes de construir todo el sistema.

Pasos realizados

  1. Diseñar la maqueta

    2. Construir la estructura de la casa y definir dónde estará cada habitación.

  2. Probar la ESP32

    3. Comprobar que la ESP32 pueda programarse correctamente.

  3. Conectar los LEDs

    4. Programar el encendido y apagado de las luces.

  4. Conectar el servomotor

    5. Programar diferentes posiciones para representar:

  5. 🔓 Puerta abierta
  6. 🔒 Puerta cerrada
  7. Conectar el LDR

    8. Leer la cantidad de luz existente.

  8. Conectar el sensor de humedad

    9. Obtener el valor de humedad.

  9. Crear la página web

    10. Diseñar el dashboard de VIERNES utilizando:

    • HTML
    • CSS
    • JavaScript
  10. Conectar la página con la ESP32

    11. Hacer que los controles de la página puedan enviar instrucciones a la ESP32 mediante Wi-Fi.

Pruebas y cambios

¿Qué probamos?

Probamos cada componente por separado y posteriormente intentamos integrarlos.
Por ejemplo:

  • Encender y apagar LEDs.
  • Mover el servomotor.
  • Leer el LDR.
  • Leer humedad.
  • Conectar la ESP32 al Wi-Fi.
  • Probar los botones de la página web.

¿Qué funcionó?

Los componentes que funcionen correctamente deben registrarse aquí.
Por ejemplo:

  • "El LED respondió correctamente a las instrucciones de la ESP32."
  • "El servomotor pudo cambiar entre las posiciones de puerta abierta y cerrada."

    • ¿Qué problemas encontramos?

    Aquí deben colocar los problemas que realmente les hayan ocurrido.
    Algunos ejemplos posibles:

    • Conexiones incorrectas.
    • Lecturas incorrectas del sensor.
    • El servo no tenía suficiente alimentación.
    • Problemas de conexión Wi-Fi.
    • Errores en el código.
    • La página no enviaba correctamente las instrucciones.

    ¿Qué cambiamos?

    Explicar cómo solucionaron cada problema.
    Ejemplo:

  • "Revisamos las conexiones y modificamos el código para corregir la lectura del sensor."
  • "Modificamos el diseño de la página para que los botones fueran más fáciles de utilizar."
